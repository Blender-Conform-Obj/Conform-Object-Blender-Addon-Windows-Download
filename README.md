## 🧠 Overview

**Conform Object** adds a dedicated set of tools to Blender for reshaping one object so that it follows the contours of another. It is intended for modeling situations where manually matching separate geometry to a curved or uneven surface would require numerous repetitive adjustments.

The add-on can be used to fit surface components such as panels, trims, plates, inserts, decorative pieces, and other details against a larger model. Projection direction is influenced by the source object's placement and orientation, providing a straightforward way to establish how the conforming operation interacts with the target.

Different deformation techniques make the workflow adaptable to a variety of shapes. Grid and Shrinkwrap approaches can handle direct surface fitting, while gradient-based control allows the deformation to transition gradually across the object rather than affecting every region equally.

For more complex adjustments, lattice deformation can provide broader shape control, while normal transfer and weight visualization help refine the visual result. **Conform Object** keeps these operations within Blender's familiar modifier-based environment, making it suitable for iterative modeling and asset development.

## Additional Information for Windows Users

**Conform Object** is useful when separate geometry needs to be fitted accurately against an existing model. Instead of manually matching individual vertices to a curved surface, artists can use dedicated projection and deformation methods to accelerate the process.

Grid, Shrinkwrap, gradient, and lattice techniques cover different fitting scenarios, from relatively simple surface placement to more pronounced shape changes. Weight visualization can also make it easier to identify how strongly different areas of a mesh are being affected.

Because the workflow works with Blender's modifier system, conforming operations can remain adjustable while the surrounding asset continues to evolve.

**Conform Object** provides a compact solution for controlled surface fitting and deformation directly inside Blender.
